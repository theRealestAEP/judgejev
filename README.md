Judge Jev is a procedural courtroom game starring **The Mostly Honorable Judge Jev**, powered by Jev from [TypeSafe AI](https://typesafe.ai/). Read five exhibits, use three minutes to raise reasonable doubt, and receive Jev’s verdict and probabilities. The game includes [50 criminal stories and 150 evidence variants](docs/scenarios.md) with mechanically generated facts, built with React, Vite, and a Cloudflare Worker. [Play at judge-jev.com](https://judge-jev.com/). For local development, run `npm install` and `npm run dev` with `JEV_KEY` in `.env.local`; production keeps the key in a Worker secret. Env files, build output, and music files are excluded from Git. This is mostly an experiment to see how Jev handles logic.
